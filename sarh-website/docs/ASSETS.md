**ملاحظات مهمة عن الصور المولَّدة**

- وُلّدت عشر صور في جلسة العمل: خمس وفق برومبتات الصور الواردة في البرومبت الأصلي (الأقسام أ–هـ)، وخمس ببرومبتات إضافية بالأسلوب نفسه (صورة محور الاستشارات والمشاريع التوضيحية). لكل محور خدمة صورته، ولم تُكرَّر صورة واحدة لكل الخدمات.
- كلها **تصورات توضيحية** وليست أعمالاً للمؤسسة. في المعرض تحمل الوسم «تصور معماري توضيحي»، وتحت صور الخدمات «تصور توضيحي».
- `service-supervision.jpg` و`service-inspection.jpg` تظهر فيهما أيدٍ أو أشخاص من الخلف دون وجوه، وهم غير حقيقيين.
- `project-residential.jpg` يُظهر شارعاً ذا طابع أوروبي؛ يُستبدل بصورة من بيئة عمل المؤسسة.
- لا تحتوي أي صورة نصاً مقروءاً؛ كل نصوص الموقع HTML حقيقي.
- صورة حادية عشرة كانت مخططة لتصنيف «مشاريع تحت الإشراف» لم تُولَّد (بلغت الجلسة حد التوليد)، فبقي التصنيف دون مشروع توضيحي.
- صورة واجهة الموقع المرفقة (`docs/reference/ui-direction-mock.png`) استُخدمت مرجعاً بصرياً فقط، وأُعيد بناء الواجهة بالكود.

## 2. المجسم الثلاثي الأبعاد

- لا يوجد ملف GLB ولا خامات صورية. المجسم **إجرائي** مكتوب بالكود في `src/components/hero/scene/model.ts` (كتل، بلاطات، أعمدة، واجهات، زجاج، تنسيق موقع)، مستوحى من كتل صورة المبنى المرفقة.
- خامة الحجر مرسومة داخل الـshader في `scene/materials.ts`، وبيئة الانعكاس مولَّدة بالكود (Lightformers) دون ملف HDR.

### إطارات الرحلة البديلة

`public/story/desktop/` و`public/story/compact/`: 41 إطاراً لكل منهما بصيغة WebP (1539×911 بمجموع 936KB، و780×718 بمجموع 675KB). هي لقطات من المجسم الثلاثي الأبعاد نفسه، التقطها `scripts/capture-story-frames.mjs` من المشهد الحي، وليست صوراً مولَّدة أو مرسومة. تُحمَّل فقط حين لا يستطيع المتصفح تشغيل WebGL، ويحمّل كل جهاز مجموعته فقط. يجب إعادة التقاطها بعد أي تعديل على المجسم.

## 3. الخطوط

| الخط | المصدر | الترخيص | الموضع |
|---|---|---|---|
| IBM Plex Sans Arabic (Regular 400، Medium 500، SemiBold 600) | حزمة npm ‏`@ibm/plex-sans-arabic` 1.1.0 | SIL Open Font License 1.1 (النص في `src/fonts/OFL.txt`) | `src/fonts/`، مستضاف ذاتياً دون طلب لأي CDN |

الملفات الكاملة محفوظة في `assets-source/fonts/` (نحو 224 KB للأوزان الثلاثة). الملفات المستخدمة في الموقع نسخة مقتطعة منها (نحو 134 KB) تضم العربية واللاتينية الأساسية وعلامات الترقيم مع كل خصائص تشكيل الحروف العربية. يُعاد بناؤها بالأمر `scripts/subset-fonts.sh` (يتطلب Python و`fonttools`). قورنت أربع صفحات نصية قبل الاقتطاع وبعده فتطابقت الصور بكسلاً ببكسل.

## 4. مكونات React Bits

منسوخة من مستودع React Bits (نسخة TypeScript + Tailwind) إلى `src/components/react-bits/`. الترخيص: MIT + Commons Clause، ويسمح بالاستخدام داخل موقع أو منتج (ومنه التجاري)، ويمنع بيع المكونات أو إعادة توزيعها منفردة.

| المكون | دوره في الموقع | التعديل |
|---|---|---|
| `AnimatedContent` | كل حركات الظهور (عبر `ui/Reveal`): ظهور متتابع، وكشف الصور بقناع | مُعاد كتابته: المحتوى ظاهر في HTML الأولي، لا يُخفى ما هو معروض أصلاً، يحترم تفضيل الحركة، ويدعم `as="span"` |
| `ShinyText` | لمعة نحاسية على اسم «صَرْح» في العنوان الرئيسي والتذييل | احترام تفضيل الحركة، وحشوة لحركات التشكيل العربية |
| `ScrollReveal` | فقرة «من نحن» تظهر كلمة كلمة مع القراءة | خاصية `as`، نسخة مخفية لقارئات الشاشة بدل `aria-label`، دون مقاسات افتراضية |
| `SpotlightCard` | بطاقات «لماذا صَرْح» الأربع | سطر واحد (كتابة المرجع داخل effect) |
| `Topography` | خطوط كنتورية خافتة خلف «لماذا صَرْح» (كمبيوتر فقط) | سطر واحد (كتابة المرجع داخل effect) |
| `LogoLoop` | شريط شعارات الشركاء، يظهر فقط عند توفر شعارات حقيقية | دون تعديل |

لم تُستخدم مؤثرات تقطيع الحروف (مثل SplitText بوضع `chars`) لأنها تفصل الحروف العربية المتصلة.

## 5. المكتبات

Next.js 16، React 19، three.js، ‏`@react-three/fiber`، ‏`@react-three/drei`، GSAP (مع ScrollTrigger و`@gsap/react`)، Tailwind CSS 4. الإصدارات مثبتة في `package-lock.json`. تراخيصها MIT، عدا GSAP الذي يُوزَّع مجاناً بترخيصه الخاص (راجع شروطه على موقع GSAP قبل الإطلاق التجاري).

## 6. الأيقونات

أيقونات خطية مرسومة يدوياً بصيغة SVG في `src/components/ui/icons.tsx`، وأيقونة الموقع المؤقتة `src/app/icon.svg`. لا توجد شعارات جهات أو اعتمادات.
