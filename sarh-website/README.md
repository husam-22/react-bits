# موقع صَرْح

موقع مؤسسة «صَرْح للاستشارات العقارية والهندسية وإدارة البناء»: موقع عربي (RTL) بمشهد ثلاثي الأبعاد يبني المبنى مع التمرير «من الأرض إلى الصرح»، وصفحات للخدمات والمشاريع والتواصل.

> **الحالة: نسخة معاينة.** الموقع يعمل كاملاً، لكن نموذج التواصل غير موصول بجهة استقبال، وبيانات المؤسسة الرسمية والمشاريع الحقيقية لم تُزوَّد بعد. التفاصيل في [`docs/MISSING-DATA.md`](docs/MISSING-DATA.md).

## التشغيل

المتطلبات: Node.js 20.9 أو أحدث.

```bash
npm install          # تثبيت الاعتماديات (الإصدارات مثبتة في package-lock.json)
npm run dev          # خادم التطوير على http://localhost:3000
npm run build        # بناء نسخة الإنتاج
npm run start        # تشغيل نسخة الإنتاج بعد البناء
npm run lint         # فحص ESLint
npm run typecheck    # فحص TypeScript
npm run images       # إعادة توليد صور الويب من assets-source/
```

سكربتان إضافيان يحتاجان أدوات خارج المشروع (التفاصيل في رأس كل ملف):

- `scripts/capture-story-frames.mjs`: يعيد التقاط إطارات الرحلة البديلة من المشهد الثلاثي الأبعاد. **شغّله بعد أي تعديل على المجسم أو خاماته أو الكاميرا.**
- `scripts/subset-fonts.sh`: يعيد بناء الخطوط المقتطعة من الملفات الكاملة.

للإعدادات: انسخ `.env.example` إلى `.env.local` واملأ ما يتوفر. كل القيم اختيارية للتشغيل؛ القيمة الفارغة تُخفي عنصرها من الواجهة.

## المشهد الثلاثي الأبعاد ورحلة التمرير

- **مجسم إجرائي واحد** في `Canvas` واحد، بخمس مجموعات: Site وPlan وStructure وEnvelope وLandscape. كل عنصر يحمل نافذة التقدم التي يُبنى خلالها.
- **قيمة تقدم واحدة.** GSAP ScrollTrigger يقيس تقدم القسم المثبت ويكتبه في `storyStore`؛ المشهد والعبارات والمؤشر كلها تقرأ القيمة نفسها. لذلك يعود كل شيء بسلاسة عند التمرير للأعلى ولا تتعارض المؤثرات.
- **التثبيت بـCSS** (`position: sticky`)، وJavaScript يقرأ موضع التمرير فقط ولا يحرّك الصفحة. شريط التمرير ولوحة المفاتيح واللمس وروابط القائمة تعمل بسلوكها الطبيعي.
- **الصورة أولاً.** النص وصورة المبنى يظهران من HTML الأولي؛ حزمة three.js تُحمَّل بعدها عند فراغ المتصفح.
- **عرض عند الطلب** (`frameloop="demand"`): لا يُرسم إطار إلا عند تغير التقدم أو المقاس.
- **جودة متكيفة بالقياس لا بنوع الجهاز:** DPR من 1 إلى 1.5، وتنخفض الدقة ثم الظلال حسب زمن الإطار المقاس. المتصفح الذي لا يملك إلا عرضاً برمجياً (دون بطاقة رسومية) يبدأ من أخف مستوى ويُحكم عليه بالقياس نفسه.
- **تقليل الحركة:** يُحترم إعداد النظام، وفي التذييل مفتاح «تقليل الحركة». عندها لا يُحمَّل المشهد ولا يُثبَّت القسم، وتظهر المراحل نصاً ثابتاً. الأمر نفسه من دون JavaScript.

### ماذا يرى كل زائر؟

| الحالة | ما يُعرض |
|---|---|
| WebGL يعمل بسلاسة | المشهد الثلاثي الأبعاد الحي |
| WebGL غير متوفر، أو فُقد سياقه، أو فشل تحميل حزمته، أو كان أبطأ من 45ms للإطار في أخف مستوى | **الرحلة نفسها كتتابع صور**: 41 إطاراً ملتقطة من المجسم ذاته تُرسم على Canvas عادي وتتبع التمرير في الاتجاهين |
| تقليل الحركة، أو شاشة قصيرة جداً، أو JavaScript معطّل | صورة المبنى الثابتة والمراحل نصاً |
| الزائر فعّل «توفير البيانات» في متصفحه | صورة المبنى الثابتة، دون تحميل الثري دي أو الإطارات |

للتجربة: أضف `?3d=frames` إلى العنوان لرؤية تتابع الصور على أي جهاز، أو `?3d=force` لتثبيت أعلى جودة للثري دي (يفيد في متصفح بلا بطاقة رسومية).

## مكونات React Bits المستخدمة

| المكون | أين | لماذا |
|---|---|---|
| AnimatedContent | كل حركات الظهور عبر `ui/Reveal` | ظهور متتابع وكشف للصور بقناع، دون تقطيع النص |
| ShinyText | اسم «صَرْح» في العنوان والتذييل | لمعة تعبر النص كاملاً فتبقى الحروف العربية متصلة |
| ScrollReveal | فقرة «من نحن» | تظهر كلمة كلمة (تقسيم على المسافات فقط) |
| SpotlightCard | بطاقات «لماذا صَرْح» | ضوء نحاسي يتبع المؤشر أو تركيز لوحة المفاتيح |
| Topography | خلفية «لماذا صَرْح» على الكمبيوتر | خطوط كنتورية ساكنة تناسب موضوع الأرض، تُحمَّل عند الاقتراب من القسم فقط |
| LogoLoop | قسم الشركاء | يعمل تلقائياً عند إضافة شعارات حقيقية |

التعديلات على كل مكون مذكورة في رأس ملفه وفي [`docs/ASSETS.md`](docs/ASSETS.md).

## نموذج التواصل

- التحقق يجري في المتصفح وعلى الخادم بالدالة نفسها (`src/lib/contact-schema.ts`)، برسائل عربية بجانب الحقول.
- الحماية: حقل مصيدة مخفي، فحص زمن التعبئة، وتحديد عدد الطلبات لكل عنوان.
- **لا نجاح وهمي:** رسالة «تم استلام طلبك» تظهر فقط بعد أن تقبل جهة الاستقبال الطلب. من دون ربط يظهر إشعار أن النموذج غير موصول، ولا يُحفظ أي شيء.
- الربط بمتغيرات البيئة: `CONTACT_WEBHOOK_URL`، أو `RESEND_API_KEY` مع `CONTACT_TO_EMAIL` و`CONTACT_FROM_EMAIL`. التفاصيل في `.env.example`.
- زر مسودة واتساب يظهر فقط بعد ضبط `NEXT_PUBLIC_WHATSAPP_NUMBER`، مع توضيح أن الإرسال يكتمل داخل واتساب.
- الموقع لا يخزّن الطلبات ولا يكتب محتواها في السجلات.

## النشر

يعمل على أي استضافة تدعم Next.js (خادم Node أو منصة مثل Vercel). قبل النشر العام:

1. أكمل البنود الإلزامية في [`docs/MISSING-DATA.md`](docs/MISSING-DATA.md).
2. اضبط `NEXT_PUBLIC_SITE_URL` واربط النموذج.
3. غيّر `NEXT_PUBLIC_SITE_MODE` إلى `production` (يزيل إشعارات المعاينة ويسمح بالفهرسة).
4. أعد البناء، ثم اختبر النموذج بطلب حقيقي.
